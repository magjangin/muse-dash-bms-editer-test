## 1. 화면 구성

```
┌ 메뉴 ─ 파일(F) · 편집(E) · 재생(P) · 미디어(M) ─────────────────────────────────┐
├ 도구 모음 ─ 새로 열기 저장 │ ↩ ↪ │ 📊 ✏️ 🧰 🎨 🎛️ │ OGG 열기 · 비디오 열기 · 폴더 열기 ┤
├──────┬───────────────────────────────┬────────────────────────────────┤
│ 파형 │ 격자                          │ 오른쪽 패널                     │
│      │ 16 11 12 13 14 15 18          │  · 홀드 검사기 (문제 있을 때만)  │
│      │                               │  · 비디오 미리보기               │
│      │ (세로 보기: 아래가 0초)        │  · HEADER (제목·BPM·레벨 …)     │
│      │                               │  · 격자 설정 (줌·배속·오프셋 …) │
│      │                               │  · 키음 (#WAV) 목록              │
├──────┴───────────────────────────────┴────────────────────────────────┤
└ 상태 줄 ─ BPM · Grid · OGG · Video · 홀드 짝 요약 ────────────────────────────┘
```

**게임이 읽는 레인은 `13` `14` `15` `18` 넷뿐입니다.** `16` `11` `12` 레인도 격자에 보이지만,
거기에 찍은 노트는 게임에서 아무 경고 없이 빠집니다(→ [muse_dash.md §1](muse_dash.md#-1-뮤즈-대시-채널-매핑-channeltolanemap)).

### 격자에 보이는 색

| 모양 | 뜻 |
|:---|:---|
| 흰 / 파란 / 빨간 네모(또는 동그라미) | 노트. 색은 **레인**으로 정해질 뿐 종류와 무관합니다 (`16` 빨강 · `12` `14` `18` 파랑 · 나머지 흰색) |
| 노란 몸통 | 짝이 맞은 **홀드** |
| 분홍 몸통 | 짝이 맞은 **샌드백** |
| 주황 점선 테두리 | 짝이 어긋난 노트 (→ [문제 해결 §홀드 검사기](troubleshooting.md#-홀드-검사기에-문제가-뜬다)) |
| 빨간 테두리 | 선택한 노트 |
| 노란 사각형 | 끌어서 고르는 중인 범위 |
| 초록 줄 | 재생 커서 |
| 격자 전체가 초록으로 한 번 번쩍 | 음원을 연 상태에서 BPM·오프셋을 바꿔 격자를 다시 그렸다는 표시 |

> 하트·장애물·고스트 같은 **다른 종류는 아직 똑같은 점으로 보입니다.** 종류는 키음 파일명(UID)으로만 구별됩니다.

## 2. 두 가지 모드 — ✏️ 가 꺼져 있을 때와 켜져 있을 때

도구 모음의 **✏️** 가 모드 스위치입니다.

| 격자에서 | ✏️ 꺼짐 (선택 모드) | ✏️ 켜짐 (편집 모드) |
|:---|:---|:---|
| 왼쪽 클릭 / 끌기 | 끈 범위의 노트를 **선택** | 그 칸에 **노트 찍기** (지금 고른 키음으로) |
| 오른쪽 클릭 | 아무 일 없음 | 격자 반 칸 안에서 **가장 가까운 노트 하나 지우기** |
| `Ctrl`/`Shift` + 왼쪽 끌기 | 지금 선택에 **더하기** (이미 고른 것은 빠짐) | 같음 — 편집 모드에서도 선택이 됩니다 |

* **편집 모드에서 노트를 찍으려면 키음(붓)이 골라져 있어야 합니다.** 안 골라져 있으면 눌러도 아무 일이 없습니다.
* 이미 노트가 있는 칸을 누르면 겹쳐 찍지 않고 **그 노트의 키음을 지금 붓으로 바꿉니다.**
* 🎨 키음 팔레트를 열거나 팔레트에서 키음을 고르면 ✏️ 가 **저절로 켜집니다.**
* 오른쪽 패널의 **격자에 맞추기**를 끄면 클릭한 자리 그대로 찍힙니다(잇단음용). 켜 두면 가장 가까운 격자 칸에 붙습니다.
* 끌어서 고를 때는 **노트의 가운데**가 사각형 안에 들어온 것만 잡힙니다.
* 재생 중에 찍거나 지우면 재생이 먼저 멈춥니다.

## 3. 마우스 조작 전체

| 어디서 | 무엇을 | 결과 |
|:---|:---|:---|
| 격자 | 왼쪽·오른쪽 클릭, 끌기 | 위 §2 표 |
| 파형 | 왼쪽 클릭 / 끌기 | 끄는 동안 재생 커서만 옮기고, **떼면 그 자리부터 재생** |
| 격자·파형 위 | 가운데 버튼 끌기 | 위와 같음. ⚠️ 음원 오프셋이 0 이 아니면 커서가 마우스에서 오프셋만큼 떨어집니다 → 파형을 왼쪽 클릭하세요 |
| 창 어디든 | 재생 중 왼쪽·오른쪽 클릭 | **그 자리에서 재생이 멈춥니다.** 스크롤바·슬라이더·메뉴를 눌러도 멈춥니다 |
| 격자 | 마우스 휠 | 스크롤. 재생은 멈추지 않습니다 |
| 홀드 검사기 목록 | 줄 클릭 | 그 노트를 선택하고 격자를 그 자리로 옮깁니다 |

## 4. 키보드

| 키 | 동작 |
|:---|:---|
| `Ctrl+N` · `Ctrl+O` | 새로 만들기 · 열기 |
| `Ctrl+S` · `Ctrl+Shift+S` | 저장 · 다른 이름으로 저장 |
| `Ctrl+Z` · `Ctrl+Y` (`Ctrl+Shift+Z`) | 되돌리기 · 다시 하기 |
| `Space` | 재생 / 정지 |
| `↑` `↓` `←` `→` | 선택한 노트 옮기기 (아래 표) |
| `Delete` | 선택한 노트 지우기 |
| `Esc` | 선택 해제 (🧰 검색 창·🎨 팔레트에서는 그 창 닫기) |

### 방향키로 옮기기

| | 세로 보기 (기본) | 가로 보기 |
|:---|:---|:---|
| 시간 뒤로(나중으로) | `↑` | `→` |
| 시간 앞으로(먼저로) | `↓` | `←` |
| 레인 바꾸기 | `←` `→` | `↑` `↓` |

* 한 번에 **지금 격자 한 칸**만큼 옮깁니다. 비트가 16이면 1/16 마디입니다.
  격자에 다시 붙이지 않고 그만큼만 옮기므로 **잇단음은 잇단음으로 남습니다.**
* 레인 순서는 화면 그대로 `16 → 11 → 12 → 13 → 14 → 15 → 18` 입니다.
* **하나라도 못 가면 아무것도 안 움직입니다.** 다른 노트와 겹치거나, 마디 범위를 벗어나거나, 레인 끝에 닿은 노트가 하나라도 있으면 전체가 제자리입니다. 패턴 모양을 지키려는 규칙입니다.
* **수직위치 고정(D)** 을 켜면 시간 쪽 이동이 막히고 레인 이동만 됩니다.

> [!WARNING]
> **키가 엉뚱한 곳으로 가는 경우가 있습니다.** 키 입력은 마지막으로 누른 곳(포커스)이 먼저 받습니다.
>
> | 방금 한 일 | 그 뒤에 누른 키 | 실제로 일어나는 일 |
> |:---|:---|:---|
> | 도구 모음 버튼·체크박스를 마우스로 누름 | `Space` | 재생 대신 **그 버튼이 다시 눌립니다** (✏️ 가 꺼짐, "가로 뷰로 돌리기"가 뒤집힘 등) |
> | 키음 목록·콤보박스·슬라이더를 만짐 | 방향키 · `Delete` | 그 칸이 받습니다. **방향키가 키음(붓)을 바꿉니다** |
> | 제목·BPM 같은 글자 칸에 커서가 있음 | `Ctrl+S` · `Ctrl+O` · `Ctrl+N` | **아무 일도 안 일어납니다.** `Ctrl+Z` 는 글자 되돌리기가 됩니다 |
>
> **격자의 빈 자리를 오른쪽 클릭**하면 키가 다시 격자로 갑니다. 두 모드 모두에서 빈 자리라면 아무것도 지워지지 않습니다.
> (→ [실사용 점검 U-1·U-2·U-3](../issues/usability_review.md))

## 5. 재생

* **`Space`** — 재생 커서가 보이면 **그 자리부터**, 없으면 **0초부터** 재생합니다. 멈추면 커서가 그 자리에 남습니다.
* **파형을 클릭하면 그 자리부터** 재생합니다. 원하는 곳을 들을 때 가장 빠른 방법입니다.
* **음원(OGG)이 없으면 재생되지 않습니다.** 키음만 따로 재생하는 기능은 없습니다.
* **재생 배속**(0.1x~1.0x) — 배경음은 음정까지 같이 내려가고 키음은 원래 속도로 울립니다(→ [beat_sync_workflow.md](beat_sync_workflow.md#배속을-낮췄을-때-달라지는-것)).
  재생 중에는 슬라이더를 잡는 순간 재생이 멈추므로 **배속을 먼저 정하고 재생**합니다.
* **키음 소리** 버튼 — 끄면 배경음만 들립니다. 음량 조절은 없습니다(켜기/끄기뿐).
  글자가 **🔊 키음 소리 켜짐** 이면 켜진 것, **🔇 키음 소리 끄기** 이면 **꺼진 것**입니다.
* **재생바 따라가기** — 커서가 화면 가운데 절반을 벗어나면 격자를 커서 쪽으로 옮깁니다.
* 정지해도 **이미 울리기 시작한 키음은 끝까지 울립니다.**
* 비디오는 재생·정지·배속을 따라 움직입니다.

## 6. 보조 창 네 개

네 창 모두 **띄워 둔 채 격자를 계속 만질 수 있고**, 종류마다 하나씩만 뜹니다.

| 창 | 하는 일 | 이럴 때 |
|:---|:---|:---|
| **🧰 검색/삭제/교체** | 조건(선택 여부 · 레인 · 마디 범위 · 번호 범위)에 맞는 노트를 **선택 · 삭제 · 번호 바꾸기 · 마디 옮겨 복사** | "12~20마디 `14` 레인에서 번호 `0A`~`0F`" 처럼 조건을 조합할 때. 후렴을 뒤쪽 마디로 복사할 때 |
| **🎨 키음 팔레트** | 넓은 판에서 붓 고르기 · 번호/파일명 검색 · 여러 개 한꺼번에 추가 · 보기 크기(목록 ~ 아주 큰 아이콘) | 키음이 많아서 사이드바 목록이 좁을 때 |
| **📊 노트 통계** | 레인별 · 키음별 개수. **보기 전용**입니다 | 숫자만 확인할 때 (잘못 눌러 바뀔 일이 없음) |
| **🎛️ 컨트롤 패널** | 한 줄을 골라 그 노트를 **전부 선택 · 미리듣기 · 일괄 교체 · 일괄 삭제(확인 후)** | "이 번호가 몇 개고 어디에 있나"에서 곧장 손댈 때. 줄을 두 번 누르면 바로 선택 |

알아 둘 것:

* 🧰 검색 창의 **[삭제]는 확인 없이 바로 지웁니다.** `Ctrl+Z` 로 되돌릴 수 있습니다. 🎛️ 컨트롤 패널의 일괄 삭제는 먼저 물어봅니다.
* 🧰 검색 창의 **"롱"·"숨기기" 필터는 잠겨 있습니다.** 이 에디터는 뮤즈 대시 노트를 전부 일반 노트로 읽기 때문입니다(홀드인지는 파일명이 정함).
* 🧰 검색 창의 마디 범위는 `0`~`999` 입니다.
* 🧰 **마디 옮겨 복사**는 이미 노트가 있는 자리와 마디 범위 밖은 건너뛰고, 건너뛴 개수를 알려 줍니다. 복사한 노트가 선택된 채로 남습니다.
* 통계·컨트롤 패널의 키음별 목록은 **노트가 실제로 쓰는 번호만** 보여 줍니다. `(등록되지 않은 번호)` 가 보이면 `#WAV` 정의가 없는 번호를 쓰는 노트가 있다는 뜻입니다.
* `Esc` 로 닫히는 것은 🧰 검색 창과 🎨 팔레트뿐입니다.

## 7. 키음(#WAV) — 노트를 찍는 붓

뮤즈 대시에서는 **키음 파일명의 앞 6자리(UID)가 노트 종류를 정합니다**(→ [muse_dash.md §2](muse_dash.md)).
그래서 "어떤 키음을 골랐나"가 곧 "어떤 노트를 찍나"입니다.

| 버튼 | 하는 일 |
|:---|:---|
| **키음 추가** | WAV 파일을 골라 빈 번호 중 가장 작은 것에 등록합니다. 번호 자릿수(2자리/3자리)는 차트에 맞춥니다. 오른쪽 패널에서는 한 개씩, 🎨 팔레트에서는 여러 개를 한 번에 고를 수 있습니다 |
| **키음 삭제** | 그 번호를 쓰는 노트가 있으면 먼저 물어봅니다. 지우면 그 노트들은 소리 없는 "유령 노트"가 됩니다 |
| **재생 테스트** | 고른 키음을 들려줍니다 |

* 새로 만들기로 시작하면 **키음 표가 비어 있습니다.** 뮤즈 대시 UID 로 이름 붙은 WAV 파일을 직접 추가해야 노트를 찍을 수 있습니다.
  건반 BMS 가져오기를 쓰면 일반 노트·홀드용 정의 6줄은 자동으로 만들어집니다(→ [keyboard_bms_downmix.md §5](keyboard_bms_downmix.md#5-자동으로-만들어지는-키음-정의)).
* 저장할 때 `#WAV` 경로는 **차트 파일 기준 상대 경로**로 적힙니다. 차트를 다른 폴더로 옮길 때는 키음 파일(씬 WAV 폴더)도 같이 옮기십시오.
* 적힌 자리에 파일이 없어 하위 폴더에서 같은 이름을 찾아 재생한 경우, 저장할 때는 **원래 적혀 있던 경로를 그대로** 둡니다.
* 재생할 수 있는 키음 형식: WAV(8/16/24/32bit PCM · 32bit float)와 OGG. 그 밖의 WAV 는 Windows 기본 재생으로 넘기는데, 이때는 화음이 안 되고 앞 소리를 끊습니다.

## 8. HEADER 와 격자 설정

### HEADER

`#TITLE` · `#ARTIST` · `#GENRE` · `#BPM` · `#PLAYER` · `#RANK` · `#LEVEL` 을 고칩니다. 비어 있는 글자 칸(제목·아티스트·장르·레벨)은 파일에 쓰지 않습니다.

* **BPM 은 소수점 넷째 자리까지** 받습니다. 바꾸면 격자가 초록으로 한 번 번쩍이며 다시 그려지고, 찍어 둔 노트도 격자를 따라 움직입니다.
* 곡 도중 BPM 변화·변박은 **넣는 화면이 없습니다.** 파일에 있는 것은 읽어서 격자에 반영하고 저장 때 원문 그대로 둡니다.

### 격자 설정

| 설정 | 범위 | 뜻 |
|:---|:---:|:---|
| 마디 수 | 1~9999 | 음원 길이와 이미 찍힌 노트가 요구하는 만큼은 **자동으로 확보**되고, 그보다 줄일 수 없습니다(최소 32) |
| 비트 / 마디 | 1~192 / 1~48 | 격자 분할. 잇단음 구간은 `12/4` · `24/4` 로 (→ [grid_specification.md](../specifications/grid_specification.md)) |
| 세로 줌 | 4~8 | 시간축 길이 |
| 그리드 가로 줌 | 0.25~4 | 레인 폭 |
| 파형 가로 줌 | 0.25~4 | 파형 **진폭** 배율. 조용한 곡에서 킥을 찾을 때 |
| 재생 배속 | 0.1~1.0 | 듣는 속도. 차트와 무관 |
| 음원 오프셋 | −200~+200ms | 음원을 타임라인에서 미는 양. **게임에는 반영되지 않습니다** (→ [beat_sync_workflow.md](beat_sync_workflow.md#-참고-음원-오프셋은-게임에-반영되지-않습니다)) |
| ⚡ 오프셋 자동 맞춤 · 0 초기화 | — | 온셋이 16분 격자에 가장 잘 붙는 오프셋을 잽니다 / 0 으로 |
| 재생바 따라가기 · 격자에 맞추기 · 수직위치 고정 · 가로 뷰 · 동그라미 | 켜기/끄기 | 위 §2~§5 참고. 이름 옆의 `(G)` `(D)` 는 **아직 단축키가 아닙니다** |

> [!NOTE]
> **격자 설정은 저장되지 않습니다.** 앱을 다시 켜면 줌·보기 방향·배속·노트 모양이 기본값으로 돌아갑니다.
> 파일에 남는 것은 HEADER 와 음원 오프셋(`#BMSEDITER_OFFSET`)뿐입니다.

## 9. 되돌리기 (`Ctrl+Z` / `Ctrl+Y`)

| 되돌아가는 것 | 되돌아가지 않는 것 |
|:---|:---|
| 노트 (찍기·지우기·옮기기·키음 교체·복사) · 키음 표 · 그때의 선택 | 제목·BPM 같은 **HEADER**, 줌·보기 방향 같은 **화면 설정** |

* 예외: **건반 BMS 가져오기**를 되돌리면 HEADER 까지 가져오기 전으로 돌아갑니다. 같이 연 음원·영상은 남습니다.
* 최대 **100칸**입니다. 넘으면 오래된 것부터 버립니다.
* **파일을 열거나 새로 만들면 기록이 비워집니다.** 저장해서는 비워지지 않으므로 저장한 뒤에도 되돌릴 수 있습니다(파일은 다시 저장해야 바뀝니다).
* 편집 메뉴에 무엇이 되돌아가는지 적혀 있습니다 — "되돌리기 (노트 삭제)".

## 10. 열기와 저장

### 열기

| 방법 | 여는 것 |
|:---|:---|
| **열기** (`Ctrl+O`) | BMS 파일 하나(`.bms` `.bme` `.bml`). **음원·영상은 같이 열지 않습니다.** 앞서 열어 둔 음원이 그대로 남으니, 다른 곡이면 OGG 를 새로 여십시오 |
| **폴더 열기** | 폴더 **바로 안**의 차트·OGG·영상을 한꺼번에 엽니다. 종류마다 폴더 이름과 같은 파일을 먼저, 없으면 이름순 첫 번째를 고릅니다. 차트가 없는 폴더면 아무것도 바꾸지 않습니다 |
| **OGG 열기** · **비디오 열기** | 음원·영상만 바꿉니다. 음원은 **OGG 만** 됩니다(MP3 는 변환 필요) |
| **건반 BMS 가져오기** | 편집 메뉴. 지금 노트를 지우고 변환 결과로 채웁니다 (→ [keyboard_bms_downmix.md](keyboard_bms_downmix.md)) |

* 인코딩(UTF-8 / BOM / Shift_JIS / CP949)은 자동으로 알아내고 저장까지 유지합니다.
* 영상은 WebView2 로 재생하므로 **MP4(H.264)나 WebM** 을 권장합니다.

### 저장

* 고친 뒤 저장하지 않았으면 제목 줄 이름 앞에 **`*`** 가 붙습니다. 저장하면 사라집니다.
* 새 문서를 처음 저장하면 파일 이름을 묻습니다. 기본 이름은 `#TITLE` 에서 만듭니다.
* 저장은 임시 파일에 끝까지 쓴 뒤 바꿔치기합니다. **직전 내용은 `원래이름.bms.bak` 으로 하나만** 남습니다.
* 원래 인코딩으로 담을 수 없는 글자(예: Shift_JIS 차트에 한글 제목)가 있으면 **UTF-8 로 저장하고 알려 줍니다.**
* 에디터가 다루지 않는 줄(BGM · BPM 변화 · `#RANDOM` 블록 · 주석 등)은 원문 그대로 되돌려 씁니다.
* 저장하지 않고 창을 닫으면 **저장하고 닫기 / 저장 안 함 / 취소** 를 묻습니다.

> [!CAUTION]
> **자동 저장은 없습니다.** 앱이 비정상 종료되면 마지막 저장 이후의 작업은 사라집니다. `Ctrl+S` 를 자주 누르십시오.
