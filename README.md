# Muse Dash BMS Editer

**Muse Dash BMS Editer**는 뮤즈 대시(Muse Dash) 및 리듬게임 커스텀 BMS(Be-Music Source) 차트를 시각적으로 확인하고 편집할 수 있는 **Avalonia UI** 기반 채보 에디터입니다.

`bms editer`의 고성능 엔진(Win32 waveOut 저지연 폴리포닉 믹서, OGG 파형/온셋 분석, 정밀 틱 타임라인 등)을 기반으로 구축되었습니다.

---

## 주요 기능 (Key Features)

1. **BMS 차트 완벽 파싱 및 안전한 라운드트립 저장**
   - BOM / UTF-8 / Shift_JIS / 한국어 완성형(CP949) 인코딩 자동 인식 및 보존.
   - 최소공배수(LCM) 분할 알고리즘을 통한 원본 마디 완벽 복원.
   - 임시 파일 원자적 교체 및 직전 상태 .bak 자동 생성.
   - #RANDOM / #IF 조건 분기 블록 구조 원문 보존.

2. **실시간 저지연 오디오 재생 및 폴리포닉 키음 믹싱**
   - NVorbis + Win32 waveOut P/Invoke 직접 제어로 즉각적인 재생 및 스크러빙.
   - 초당 피크 및 온셋(Onset) 마커 실시간 시각화.
   - 이진 탐색 기반 고밀도 채보 키음 트리거 및 백그라운드 멀티채널 Saturation Clamping 믹싱.
   - 0.1x ~ 1.0x 배경음 재생 배속 조절 및 키음 On/Off 토글.

3. **정밀 타임라인 엔진 (ChartTimeline)**
   - time = tick * 240 / bpm 공식 기반 마디 <-> 시간 양방향 변환.
   - 가변 박자 및 중간 BPM 변경(#BPMxx / #xxx08) 완벽 지원.

4. **BGA 영상 미리보기 연동**
   - WebView2 기반 비디오 타임라인 동기화.

5. **노트 통계 및 편집 공구함**
   - 조건 검색, 일괄 삭제/교체, 마디 이동 복사, 실시간 레인/키음 통계.
   - 되돌리기 / 다시 하기 (`Ctrl+Z` · `Ctrl+Y`). 노트와 키음 표를 함께 되돌립니다.

6. **뮤즈 대시 홀드 짝 검사기**
   - `#WAV` 파일명 앞 6자리 UID로 홀드·샌드백을 가려내고, 같은 채널에서 나온 순서로 짝을 맞춥니다.
   - 짝이 맞은 홀드는 격자에 **몸통**으로 그리고(홀드 노랑 · 샌드백 분홍), 어긋난 자리는 주황 점선으로 표시합니다.
   - **게임을 켜기 전에** 짝이 깨진 마디를 목록으로 알려줍니다. 줄을 고르면 그 자리로 격자가 이동합니다.

7. **4K/7K BMS → 뮤즈 대시 2레인 자동 변환**
   - 건반 BMS 가져오기에서 원본 하나를 선택하면 노트·홀드 정의를 자동 생성합니다. 별도 뮤즈 대시 차트는 필요 없습니다.
   - 4K는 1·2번 건반 → 지상(13), 3·4번 → 공중(14). 7K는 왼쪽 3개 → 지상, 오른쪽 3개 → 공중, 가운데는 번갈아 배분합니다.
   - 롱노트는 원본 게임 규칙대로 **시작·끝 노트**(키음 값·파일명)로 읽어 같은 출력 레인의 홀드 시작·끝으로 변환합니다. 원본 게임들이 쓰지 않는 `51~59` 채널과 `#LNOBJ`는 읽지 않습니다. 동시치기·홀드 충돌은 반대 레인으로 옮기고, 양쪽 모두 불가능하면 제외 수를 알립니다.
   - 제목·BPM·변속·마디 길이를 가져오며 변환은 한 번의 되돌리기로 취소할 수 있습니다.
   - 노트 정의 생성에는 WAV 파일이 필요 없지만 효과음 미리듣기에는 해당 씬 WAV 파일이 필요합니다. 오디오 파일 자체를 생성하거나 복사하지는 않습니다.
   - **곡 폴더째 가져오기**: 원본 폴더에 음원(`.ogg`)·영상이 있으면 같이 엽니다. 원본 차트가 그 음원에 맞춰져 있어 바로 들어 볼 수 있습니다.
   - 게임별 화면 배치(건볼트·스타트레일·스타게이저)를 따르고, 한쪽 레인으로 쏠리면 무거운 레인을 지상·공중 번갈아로 돌려 균형을 맞춥니다.
   - 규칙·레인 배분·실측(20곡 · 짝 문제 0건)은 [🎹 건반 BMS 다운믹스 가이드](docs/guides/keyboard_bms_downmix.md)에 정리했습니다.

## 빌드 및 실행 방법

### 요구사항
- .NET 10.0 SDK 이상
- Windows OS (Win32 P/Invoke 오디오 엔진 사용)

### 빌드 및 테스트
```powershell
# 솔루션 빌드
dotnet build "muse dash bms editer.slnx"

# 단위/통합 테스트 실행
dotnet test "muse dash bms editer.slnx"
```
