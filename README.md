# 🎵 Muse Dash BMS Editer

**뮤즈 대시(Muse Dash) 커스텀 채보를 BMS 파일로 만들기 위한 전용 에디터입니다.**

음원 파형을 보면서 노트를 찍고, 뮤즈 대시 규칙에 맞게 저장합니다.
일반 BMS 에디터로는 보이지 않는 **홀드·샌드백 짝**을 게임을 켜기 전에 잡아 주고,
인터넷에 있는 **건반 BMS(4K/5K/7K)를 뮤즈 대시 두 레인으로 자동 변환**해 리듬 뼈대를 한 번에 깔아 줍니다.

## 🤔 왜 전용 에디터가 필요한가요?

뮤즈 대시 커스텀 채보 모드는 BMS 파일을 읽습니다. BMS 파일은 일반 BMS 에디터로도 열 수 있지만,
뮤즈 대시는 **노트 종류를 노트가 아니라 `#WAV` 파일명에 적습니다.**

```
#WAV01 011001_normal.wav     ← 일반 몬스터
#WAV02 010201_hold.wav       ← 홀드     (파일명 앞 6자리 UID 중 3~4번째 자리가 02)
#WAV03 010401_sandbag.wav    ← 샌드백   (3~4번째 자리가 04)
#WAV04 000201_hp_heart.wav   ← 하트     (앞 4자리가 0002 — 3~4번째가 02여도 홀드가 아님)
```

그래서 일반 에디터에서는 **몬스터·하트·홀드·샌드백이 전부 똑같은 점**으로 보입니다.
홀드는 "같은 레인에서 홀수 번째가 시작, 짝수 번째가 끝"이라는 규칙으로 짝을 맞추는데,
하나라도 빠지면 그 뒤의 짝이 전부 어긋납니다. 이걸 **게임을 켜 봐야만** 알 수 있었습니다.

이 에디터는 뮤즈 대시의 이 규칙을 알고 있습니다.

| | 일반 BMS 에디터 | 이 에디터 |
|:---|:---|:---|
| 홀드·샌드백 | 시작과 끝이 따로 떨어진 점 | 짝을 맞춰 **몸통으로** 그림 (홀드 노랑 · 샌드백 분홍) |
| 짝이 깨졌을 때 | 게임에서 발견 | **게임을 켜기 전에** 깨진 마디 목록을 보여 줌 |
| 새 채보 시작 | 노트를 하나하나 찍기 | 건반 BMS를 가져와 **리듬 뼈대를 자동 생성** |
| BPM 변경 저장 | 에디터마다 다름 | 모드가 읽는 방식(`#BPMxx` + `08` 채널)으로 자동 저장 |

## ✨ 주요 기능

### 🎹 건반 BMS → 뮤즈 대시 2레인 자동 변환
- 같은 곡의 4K/5K/7K BMS 하나만 있으면 **지상(`13`)·공중(`14`) 배치와 홀드**를 한 번에 받습니다. 뮤즈 대시 차트나 WAV 파일은 필요 없습니다.
- 4K는 1·2번 건반 → 지상, 3·4번 → 공중. 7K는 왼쪽 → 지상, 오른쪽 → 공중, 가운데는 번갈아 배분합니다.
- 한쪽 레인으로 쏠리면 자동으로 균형을 맞춥니다 (실측 20곡 평균 지상 비율 50.7%).
- 롱노트는 같은 출력 레인의 홀드 시작·끝으로 바꾸고, 동시치기·홀드가 겹치면 반대 레인으로 옮깁니다.
- 원본 폴더에 음원(`.ogg`)·영상이 있으면 **같이 열어서** 바로 들어 볼 수 있습니다.
- 제목·BPM·변속·마디 길이도 가져오고, `Ctrl+Z` 한 번으로 통째로 되돌릴 수 있습니다.
- 📖 [건반 BMS 다운믹스 가이드](docs/guides/keyboard_bms_downmix.md)

### 🔗 홀드·샌드백 짝 검사기
- `#WAV` 파일명의 6자리 UID로 홀드·샌드백을 가려내고, 같은 레인에서 나온 순서대로 짝을 맞춥니다.
- 짝이 맞으면 격자에 몸통으로 그리고, 어긋난 자리는 **주황 점선**으로 표시합니다.
- 짝이 깨진 마디를 목록으로 보여 주고, 줄을 고르면 그 자리로 이동합니다.

### 🎧 파형 보면서 박자 맞추기
- OGG 음원의 **파형과 온셋(음의 시작점) 마커**를 격자 옆에 그립니다.
- **⚡ 오프셋 자동 맞춤**: 음원의 어택을 분석해 16분 격자에 가장 잘 맞는 오프셋을 계산합니다.
- 재생 배속 **0.1x ~ 1.0x** 로 느리게 들으며 귀로 확인할 수 있습니다.
- 노트 키음을 실시간으로 섞어 재생합니다 (WAV/OGG, 화음·연타 지원). 키음만 끄고 음원만 들을 수도 있습니다.
- BGA 영상을 재생 위치에 맞춰 함께 보여 줍니다.
- 📖 [박자 맞추기 작업 가이드](docs/guides/beat_sync_workflow.md)

### ✏️ 편집 도구
- 격자 스냅 on/off (잇단음은 끄고 찍기), 세로·가로 보기 전환, 네모/동그라미 노트 모양.
- **되돌리기 / 다시 하기** (`Ctrl+Z` · `Ctrl+Y`) — 노트와 키음 표를 함께 되돌립니다.
- 🧰 조건 검색 · 일괄 삭제 · 일괄 교체 · 마디 이동 복사
- 🎛️ 컨트롤 패널: 레인·키음별로 노트를 한꺼번에 골라 포커스·미리듣기·교체
- 📊 레인·키음별 노트 통계

### 💾 원본을 망가뜨리지 않는 저장
- 인코딩(UTF-8 / BOM / Shift_JIS / CP949)을 자동으로 알아내고 **그대로 유지**합니다.
- 원래 마디 분할을 최소공배수(LCM)로 복원해서, 열고 저장만 하면 원본과 내용이 같습니다.
- `#RANDOM` / `#IF` 조건 분기 블록을 원문 그대로 보존합니다.
- 임시 파일에 먼저 쓴 뒤 교체하고(원자적 저장), 직전 상태를 `.bak`으로 남깁니다.

### ⏱️ 정밀 타임라인
- 마디 위치 ↔ 시간 변환을 한 곳(`ChartTimeline`)에서 처리합니다. 기본 식은 `time = tick × 240 / bpm` 입니다.
- 곡 중간 BPM 변경(`#BPMxx` / `#xxx08`)과 변박(`#xxx02`)에서도 격자·파형·재생 위치가 맞습니다.

## 🛠️ 채보 하나를 만드는 흐름

```
① 시작          건반 BMS 가져오기 (편집 → 건반 BMS 가져오기)  또는  새로 만들기 + OGG 열기
                  ↓
② 박자 맞추기    BPM 입력 → ⚡ 오프셋 자동 맞춤 → 느린 배속으로 들으며 확인
                  ↓
③ 노트 배치      지상(13) · 공중(14) 레인에 노트 찍기 / 뼈대 다듬기
                  ↓
④ 종류 얹기      #WAV UID 로 하트 · 장애물 · 고스트 · 보스 등 지정
                  ↓
⑤ 짝 검사        상단 홀드 요약과 목록에서 깨진 짝 확인
                  ↓
⑥ 저장           Ctrl+S → 뮤즈 대시 커스텀 채보 모드로 게임에서 확인
```

뮤즈 대시 BMS 규칙(채널·UID·홀드 짝·BPM)은 📖 [뮤즈 대시 연동 가이드](docs/guides/muse_dash.md)에 정리되어 있습니다.

| 채널 | 역할 |
|:---:|:---|
| `13` | 지상 레인 |
| `14` | 공중 레인 |
| `15` | 보스 등장·퇴장 |
| `18` | 보스 공격 |

## 🚀 빌드와 실행

### 요구 사항
- **Windows** (오디오 재생에 Win32 `waveOut`, 영상에 WebView2를 씁니다)
- [.NET 10 SDK](https://dotnet.microsoft.com/download)

### 명령어

```powershell
# 실행
dotnet run --project "muse dash bms editer/muse dash bms editer.csproj"

# 테스트 (200개 넘는 단위·통합 테스트, 화면 없이 창까지 띄워 확인)
dotnet test "muse dash bms editer.slnx"

# 배포용 exe 하나로 묶기 → publish/win-x64/
dotnet publish "muse dash bms editer/muse dash bms editer.csproj" -p:PublishProfile=win-x64
```

## ⚠️ 현재 한계

솔직하게 적어 둡니다. 자세한 내용은 [알려진 문제](docs/issues/known_issues.md)와 [채보 작성 시간](docs/issues/authoring_time.md) 문서에 있습니다.

- **아직 시간이 오래 걸립니다.** 뮤즈 대시 340노트 채보에 약 4시간이 걸렸고, 절반 이상이 "맞게 찍었는지 확인하는 데" 들었습니다.
  이후 추가한 다운믹스·짝 검사·되돌리기로 얼마나 줄었는지는 아직 다시 재 보지 않았습니다.
- **홀드·샌드백 말고는 노트 종류가 화면에 안 보입니다.** 하트·장애물·고스트는 여전히 똑같은 점입니다.
- **다운믹스 결과는 리듬 뼈대입니다.** 건반 BMS에는 뮤즈 대시 노트 종류 정보가 없어서, 종류는 사람이 얹어야 합니다.
  변환은 실제 차트 20곡으로 확인했지만, 그 결과로 한 곡을 끝까지 완성해 게임에서 플레이해 본 적은 아직 없습니다.
- **`#RANDOM` 분기는 보존만 합니다.** 분기를 골라서 보거나 편집할 수는 없습니다.
- **Windows 전용**입니다.

## 📂 프로젝트 구조

```
muse dash bms editer/
├── Models/          BMS 차트·헤더·노트·BPM 변경·게임 프로파일
├── Services/        파서/라이터, 타임라인, 오디오 디코딩·재생, 파일 안전 저장
│   ├── Downmix/     건반 BMS → 2레인 변환
│   └── Holds/       홀드·샌드백 짝 맞추기
├── ViewModels/      MVVM 뷰모델 (CommunityToolkit.Mvvm)
├── Views/           창과 격자·파형·영상 컨트롤
└── Profiles/        게임별 홀드 짝 규칙 (JSON, exe 안에 포함)
muse dash bms editer.Tests/   xUnit + Avalonia Headless 테스트
docs/                         설계 원리, 게임별 가이드, 계획서, 이슈 기록
```

코드 구조 설명은 📖 [code_explanation.md](docs/architecture/code_explanation.md), 전체 문서 목록은 📖 [docs/README.md](docs/README.md)에 있습니다.

## 📜 참고

- 이 프로젝트는 **비공식 팬 제작 도구**이며 PeroPeroGames와 관계가 없습니다. Muse Dash는 PeroPeroGames의 상표입니다.
- 이 저장소에는 **게임 파일·음원·채보가 들어 있지 않습니다.**
- 만든 BMS를 게임에서 불러오는 **모드는 이 저장소에 포함되어 있지 않습니다.**
- 원래 여러 리듬게임용 범용 BMS 에디터에서 시작해 뮤즈 대시 전용으로 좁힌 프로젝트라,
  `docs/guides/`에는 식스타 게이트·건볼트 레코즈 등 다른 게임 가이드도 남아 있습니다.
